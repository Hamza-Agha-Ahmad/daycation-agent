#### Description:
I built a WhatsApp chat-bot that turns messy tourist messages like “desrt sfari tomrrow 3 pax” into ready-to-book links for 134 UAE experiences.  
The bot uses fuzzy search, natural-language date parsing, and returns ≤ 3 hyperlinks pre-filled with customer data — all in under 3 seconds.  
It also detects CS keywords and logs every interaction for audit.  
Built with Node.js, React, Fuse.js, Chrono, and 134 Bokun tours — no cloud DB needed.
